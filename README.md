# WhatDate — Google Play Review Demonstration Videos

This repository hosts demonstration videos for **WhatDate** (com.whatdate) to fulfill Google Play Console declaration requirements.

---

### 1. Foreground Service: Connected Device
* **File:** [video_connected_device_permission.mp4](video_connected_device_permission.mp4)
* **Declared Permission:** FOREGROUND_SERVICE_CONNECTED_DEVICE
* **Task:** Continuous data transfer to an external device.
* **Description:** Demonstrates the user navigating to the Friends screen and launching the **"Find nearby friends"** discovery service. The app initiates local peer-to-peer scanning (powered by Google Nearby Connections) to detect nearby phones and synchronize calendar memories and photos without internet.

---

### 2. Foreground Service: Data Sync
* **File:** [video_data_sync_permission.mp4](video_data_sync_permission.mp4)
* **Declared Permission:** FOREGROUND_SERVICE_DATA_SYNC
* **Task:** Local processing (Importing/exporting) & Network processing (Other).
* **Description:** Demonstrates the user navigating to Settings and exercising the **Export** and **Backup** processes. This shows the local processing required to package encrypted database archives and data packs, as well as the background synchronization service.

---

### 3. Usage & Customization: How-To
* **File:** [howto_create_whatdate_and_themes.mp4](howto_create_whatdate_and_themes.mp4)
* **Description:** Demonstrates creating a new WhatDate event using Quick Add, verifying the event on the Home timeline, and customizing the app theme via the live preview Theme picker.

---

*All videos are unedited screen captures recorded directly from an authentic test device.*
